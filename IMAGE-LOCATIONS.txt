HOW TO CHANGE AN IMAGE
------------------------------------------------------------------------
Easiest: keep the filename identical and just overwrite the file in
public/images/ with your new picture (same name = zero code changes needed).

To use a NEW filename instead: open the file:line listed above and replace
the path string, e.g.
    heroImage: '/images/Untitled design 21.png'
 -> heroImage: '/images/my-new-photo.jpg'
Then place my-new-photo.jpg inside public/images/.

Note: many "Untitled design N.png" files are reused in multiple spots across
this list (e.g. "Untitled design 9.png" appears on the About team grid AND
the Destination Weddings service gallery AND the Kolkata studio AND an
Instagram post AND the homepage LocationsSection). Changing that one file
changes it everywhere it's used — check this list before replacing a shared
file if you only want to change it in ONE place (in that case, give it a
new filename and update just that one line instead).
